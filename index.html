Jede Regel ordnet Transaktionen anhand von Regex-Mustern (Name / Verwendungszweck / Bank-Kategorie) einer Kategorie und einer Gruppe zu. Die erste passende Regel (höchste Priorität) gewinnt. Ohne Treffer wird auf die Bank-Kategorie zurückgefallen.

Unklassifizierte Ausgaben (aktuell gewählter Jahresfilter) als kompakte, nach Summe sortierte Händlerliste + aktuellem Regelwerk + fertigem Prompt exportieren — die Datei kann direkt einem LLM gegeben werden, das ein erweitertes SETTING zurückgibt (oben importierbar).

App-Sprache

Wähle die Sprache der Benutzeroberfläche. Deine Regeln/Kategorien-Bezeichnungen ändern sich dadurch nicht.

Lade hier deine CSV-Datei und stelle bei Bedarf das Format ein, falls dein Export nicht dem MoneyMoney-Standard entspricht.

Spaltenzuordnung
